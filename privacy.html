Privacy Policy

Last updated: 16 November 2026

Who this covers

Clips4days is a personal tool used only with TikTok accounts controlled by its owner. It has no other users.

What data is accessed

  • TikTok basic profile (user.info.basic): the account's display name and open ID, used only to show which account is connected.
  • Video upload (video.upload): used only to send the owner's finished clips to the account's TikTok inbox as drafts.

Clips4days does not read followers, messages, viewing history or any other TikTok data.

Where data is stored

Access tokens are stored only on the owner's own computer and are used only to call TikTok's API. No data is sold, shared with third parties or used for advertising.

Deleting data

Revoking access in the TikTok app (Settings and privacy → Security → Apps and services) stops all access. The locally stored token can be deleted at any time.
